# V2 de prueba

Esta carpeta contiene la nueva versión integral de Solicitudes Patrimonio. La versión publicada en la raíz no se modifica mientras se prueba V2.

Antes de probar el panel completo, ejecutar una sola vez `supabase-v2.sql` en el SQL Editor de Supabase.

La V2 se podrá probar en `/Solicitud-patrimonio/v2/` una vez creado `index.html`.
